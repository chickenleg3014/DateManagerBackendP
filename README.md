# 🚀 [DateManagerBackend] 백엔드 API

>위치 데이터를 기반으로 맞춤형 데이트 코스를 추천하고 생성해 주는 백엔드 API 서버

---

## 🛠 기술 스택

- **Language & Framework:** Java 21, Spring Boot 4.x
- **Database** Oracle 18c XE
- **ORM:** Spring Data JPA
- **API Docs:** Swagger (OpenAPI 3.0)
- **Deployment:** 추후 입력
